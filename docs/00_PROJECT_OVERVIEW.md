# Project Overview

## Product Name

Working name: **Classroom Intelligence**

## One-Line Description

An AI-powered assessment intelligence platform that helps CBSE teachers convert student answers into actionable teaching decisions.

## Core Promise

Teachers should not stop at marks.

Every answer should reveal:

- what a student understands,
- what they misunderstand,
- which concepts need reteaching,
- how the class is progressing,
- and what the teacher should teach next week.

## Target Users

Primary:
- CBSE teachers
- school academic coordinators
- subject heads

Secondary:
- school leaders
- students receiving teacher-approved explanations

## MVP Scope

The MVP includes:

- teacher authentication,
- classroom setup,
- student management,
- static CBSE curriculum structure,
- assessment creation,
- response ingestion,
- Hermes-based evaluation,
- student and class insights,
- weekly teacher planner,
- sponsor-powered voice and resource enrichment,
- neo-brutalist landing page,
- deployed demo.

## Product Boundaries

Out of scope for MVP:

- physical answer-sheet scanning hardware,
- full school ERP,
- parent portal,
- attendance,
- fees,
- live classroom monitoring,
- autonomous grading without review,
- Dodo Payments checkout,
- complete multilingual support.

## Core Product Principle

Use a deterministic application workflow with specialized Hermes agents.

Hermes provides intelligence, but the application owns:

- workflow state,
- permissions,
- validation,
- storage,
- review,
- and final teacher control.
