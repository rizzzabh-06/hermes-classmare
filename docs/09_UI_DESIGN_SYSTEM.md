# UI Design System

## Visual Direction

Neo-brutalist, teacher-friendly, playful, and premium.

Inspired by:

- thick borders,
- offset shadows,
- flat colors,
- bold typography,
- card-driven layout,
- tactile interactions.

## Core Tokens

Background:
- warm off-white

Borders:
- dark, thick, high contrast

Shadows:
- hard offset shadows
- no soft glassmorphism

Typography:
- bold display face
- clean readable body face

Accent colors:
- yellow
- pink
- blue
- mint
- orange
- purple

## Interaction Rules

Buttons:

- visible border,
- clear hover movement,
- pressed state reduces shadow,
- keyboard focus ring.

Cards:

- slight hover lift,
- limited rotation,
- never compromise readability.

## Required States

Every data screen includes:

- loading,
- empty,
- error,
- success,
- permission denied.
